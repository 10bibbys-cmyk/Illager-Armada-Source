# Illager Armada 1.0.1.1

Stable maintenance release. Adopts the four-part version number and publishes source for transparency; does not change the naval gameplay from 1.0.1.

The 1.0.1 gunnery crash correction is retained. All Java code, Mixins, ship AI, cargo manifests, configuration values and persistence are unchanged.

For the full changelog see `release/CURSEFORGE_CHANGELOG_1.0.1.1.md`.

Minecraft 1.20.1 · Fabric · Small Ships 2.0.2 · Java 17. Install on both client and server.
